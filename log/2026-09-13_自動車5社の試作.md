# 2026-09-13 自動車5社の試作

## やったこと

- トヨタ1社で、決算をステータス画面にする試作を作った（規模Lv・攻撃力・防御力・素早さ・HP・状態異常・今期受けたダメージ・次の期の見通し）
- 同業種でホンダ・日産・スズキ・マツダを足し、5社の一覧を作った。数字は各社の2026年3月期 決算短信（連結）の原本PDFから
- `data/companies.json` → `tools/make_status.py` で全ページを作り直す形にした
- giraffess リポジトリから分離した

## 見つけたこと

- **「レベル」だけだと経営の点数に見える。**ホンダは営業赤字なのに2位のLv.86。「規模Lv.」に直した
- **HPの式（現金÷1か月の費用）は、強さとずれる。**スズキは攻撃力・防御力とも5社で一番なのに、HPは最下位の2.1か月
- 金融事業（自動車ローン）を持つ会社は、防御力とHPが低めに出る

## つまずいたことと直し方

- 検索で出たまとめサイトが、トヨタの自己資本比率を個別の74.8%や、誤りの36.8%で載せていた → 決算短信の原本（連結 37.8%）に揃えた
- ホンダの短信を `pdftotext` で読むと表の列がずれ、非支配持分を含む当期利益が親会社帰属の欄に見えた → 本文の損益計算書で確かめた
- スズキはIFRSなので「自己資本比率」という項目が無い。1ページ目の自己資本比率は個別の数字 → 連結の「親会社所有者帰属持分比率」を使った

## 追記：四季報のように全社へ広げる形にした

- ページを `index.html`（検索・業界一覧）／`industry/<業種>.html`（規模Lvが高い順）／`company/<証券コード>.html`／`about.html`（数字の考え方）に分けた。旧URL（`トヨタ.html` など）は消えた
- データを `data/companies/<証券コード>.json` に1社1ファイルで持つ形にした
- `tools/fetch_edinet.py` を作った。**EDINET API v2 はキーが無いと401。**コードリスト（社名・よみ・業種・証券コード）はキー無しで取れる
- 上場の内国法人は3,821社（2026-09-13のコードリスト）。金融4業種（銀行83・証券33・保険15・その他金融44）は式が合わないので外す
- 検索は、よみがな（コードリストのカタカナ）をひらがなに寄せて、「とよた」でも引けるようにした
- 320px と 1920px で横スクロールが出ないことをブラウザで確認した

## 追記：EDINETの実データで試した（輸送用機器81社）

- 80社取れた。取れなかったのは ARCHION（543A）だけ。上場1期目で、前期の数字が報告書に無い
- **決算短信から手で入れた4社（ホンダ・日産・スズキ・マツダ）と、有報から自動で読んだ数字を突き合わせた。**ホンダ・日産・マツダは全項目一致
- スズキは当期の数字は一致。**前期の数字だけ有報のほうが違った**（売上 5兆8,251億円→5兆8,430億円 など）。有報で前期を修正して載せているため。自動で取る会社は、有報の前期の数字を使う
- 取りこぼし2件を直した
  - トヨタ：売上高の要素IDが `TotalNetRevenuesIFRS`／`OperatingRevenuesIFRSKeyFinancialData`。候補に足した
  - 川崎重工業：IFRSで営業利益を出さず、**事業利益**（`BusinessProfitLossIFRS`）を出している。営業利益が無いときだけ使い、ページに「事業利益率」と書く
- 最初の実行は、取れなかった理由の出し方にバグがあった（連結で足りない項目ではなく、個別で足りない項目を出していた）。直した
- イクヨ（7273）は売上が70%伸びている。報告書の数字どおり

## 運営の負担を減らす形にした

- 毎朝6時に GitHub Actions が、前回見た日以降の書類一覧だけを見て、新しい有報が出た会社だけ読む。ページを作り直して公開まで自動
- 状態は `data/filings.json`（上場企業3,823社の最新の有報の番号）。初回の取り込みは1回1,500社ずつ
- 更新は1社につき年1回。四半期報告書は2024年に無くなったので、月ごとの更新はEDINETではできない
