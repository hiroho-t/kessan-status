# 決算をゲームのステータスで見せるメディア（2026-09-13）

> **状態：進める（社長の判断 2026-09-13）。**「コーポックと決算ステータスはやりたい」。コーポックと並べて進める。審査はまだ。

## 0. 社長の原文

> 会社の決算資料って読みたくてもよめない社会人も多いと思う。でも投資家とか経営者とか会計士にはちゃんと読めているし、会社の状況を正しく把握できていると思う。
> そこで、一般の知識がない人でも会社の状況がわかるようにポケモンみたいなレベルや強さとかみたいに視覚的に指標を変えたシンプルな決済一覧メディアを作れないかな？
> これもビジネスモデルは不明だけど、情報が伝わることで、投資や採用に影響すると思う。

**名前は仮。**ポケモンの名前・絵・言葉は使わない（他社の知的財産）。**「ゲームのステータス風」**として書く。

---

## 1. ひっくり返す一言

> **売っているのは決算の解説ではなく、「読めなくても、会社の強さが一目で分かる」こと。**

---

## 2. キーニーズ法

**使う人が2通りいる。**

| | 投資を始めた人 | 就職・転職を考えている人 |
|---|---|---|
| **A 行動** | 名前を知っている会社の株を、なんとなく買っている | 求人票と口コミだけを見て、応募先を決めている |
| **B 不快** | **決算を開いても読めない。**分からないまま買っている | **その会社が危ないのか、伸びているのか分からない** |
| **C ニーズ** | 自分で納得して、お金を預けたい | 数年後もなくならない会社で働きたい |
| **一文** | 「読めないのに、それでも名前だけで株を買っているのは、自分で納得してお金を預けたいから」→ **通る** | 「危ないか分からないのに、それでも口コミで応募先を決めているのは、なくならない会社で働きたいから」→ **通る** |

### 潜在ニーズ

| | 形 | 採るか |
|---|---|---|
| （Ⅰ）決算を読んでも、分からない不快なく把握したい | 採らない（読み方を教える＝教育になる） |
| （Ⅱ）**決算を読まずに、会社の状態を把握したい** | **採る。**ステータス画面だけで分かる |

## 3. 見せ方の案（すべて仮）

| ゲームの言葉 | 決算の何を当てるか |
|---|---|
| **レベル** | 売上の規模 |
| **攻撃力** | 稼ぐ力（営業利益率） |
| **防御力** | 倒れにくさ（自己資本比率） |
| **素早さ** | 伸びる速さ（売上の成長率） |
| **HP** | 手元の現金で、何か月もつか |
| **タイプ** | 業種 |
| **状態異常** | 赤字が続いている、債務超過 など |
| **進化** | 事業の中身が大きく変わった年 |

**指標の選び方と、数字をステータスに変える式は、会計の専門家に一度見てもらう。**

## 4. 土台（確認した範囲）

| | 中身 |
|---|---|
| **EDINET API** | 金融庁。有価証券報告書をプログラムで取得できる。**メールアドレスを登録すれば、APIキーは無料で発行される。**XBRL形式で財務データが取れる |
| 対象 | **有価証券報告書を出している会社（上場企業など）。非上場の中小企業は、ここからは取れない** |

## 5. 既存（確認した範囲）

| 既存 | 足りないところ |
|---|---|
| **バフェット・コード**（2018年開始・無料で使える財務分析ツール） | **個人投資家向け。**指標とグラフは揃っているが、読めない人向けではない |
| IR BANK など | 同上 |
| 会計を学ぶゲーム・研修（「財務の虎」など） | **読み方を学ぶ側。**会社一覧のメディアではない |

**決算を、会社ごとのゲームのステータス画面として一覧にしているサービスは、今回の検索では見つからなかった。**

## 7. 法務の線（重い。進めるなら最初に確認する）

| 論点 | 中身 |
|---|---|
| **投資助言** | 金融庁の監督指針では、**不特定多数に向けて、誰でもいつでも自由に見られる形**の情報提供は、投資助言・代理業の登録が要らない場合がある。**会員登録しないと見られない形や、個別性の高い情報は、登録が要る**（検索結果で確認。**専門家への確認はまだ**） |
| 線 | **「強い＝買い」と書かない。**おすすめ銘柄を出さない。**会員限定の有料情報にしない** |
| 知的財産 | ポケモンの名前・絵・言葉は使わない |

**この線を守ると、「会員限定で有料」という一番分かりやすい収入の形が使えない。**

## 8. ビジネスモデル（候補だけ）

| 候補 | 中身 | 気になるところ |
|---|---|---|
| 広告 | 証券会社の口座開設の広告 | 投資を勧めているように見えないか |
| 就職・転職の側 | 求人サービスとの連携 | 掲載料をもらうと、ステータスの公平さが疑われる（`34` 線3と同じ） |
| 企業向け | 自社のステータス画面を、採用ページやIRに貼れる形で提供 | **点が悪い会社は使わない** |
| 本・グッズ | 「業界ごとのステータス図鑑」 | 出版物なら投資助言の論点が軽くなる可能性（要確認） |

**まだ決めない。**

---

## 9. オンラインの実証実験（案）

> **ステータス画面で見せると、決算を読めない人が、会社の状態を正しく当てられるようになるのか。**

| | 中身 |
|---|---|
| やり方 | Webアンケートで、同じ会社の決算を**A群には普通の表で、B群にはステータス画面で**見せる |
| 聞くこと | 「この会社は、稼ぐ力が強いか」「倒れにくいか」などを答えてもらい、**正解率を比べる** |
| 仮説 | H1 B群のほうが正解率が高い／**H2 B群のほうが、間違った印象（見た目が強いから安全、など）も増える** |

**H2が当たったら、見せ方を直す。**分かりやすさが誤解を生むなら、メディアとして危ない。
